# 🚗 Concesionario Sport - Simulador de Compra

Bienvenido a **Concesionario Sport**, un simulador de compra de autos desarrollado con JavaScript puro y almacenamiento local. Este proyecto tiene como objetivo simular el proceso de selección y compra de vehículos, ofreciendo una experiencia interactiva para el usuario.

---

## 🌐 Demo online

▶️ **[Probar el simulador en Netlify](https://helpful-tanuki-e4dc1a.netlify.app/)**

Podés ingresar y utilizar la app directamente desde cualquier dispositivo.
La demo se utiliza una base de datos de firebase

---

## 🧠 ¿Qué aprendí con este proyecto?

- Manipulación del DOM con JavaScript puro
- Uso de `localStorage` para almacenar datos
- Simulación de carrito de compras
- Renderizado dinámico de productos
- Validaciones básicas en formularios

## ⚙️ Funcionalidades principales

✅ Visualización de autos disponibles  
✅ Agregado de autos al carrito

✅ Cálculo del total de compra
